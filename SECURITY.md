# Security policy

Do not report product vulnerabilities in public issues. Contact the repository owner through an agreed private channel.

This repository is public distribution infrastructure. Never commit:

- signing private keys or recovery secrets;
- Wi-Fi, SIP or administrator credentials;
- device identifiers, MAC addresses, call history, logs or telemetry;
- proprietary firmware source code.

A release must remain unpublished until its signature, hashes, hardware compatibility, rollback behaviour and recovery path have been verified. GitHub account access alone must never be sufficient to make a device install arbitrary firmware.
